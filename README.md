# ⚡ FocusFlow — Daily Efficiency Hub

A clean, distraction-free web application built for the **Triple H Hackathon** to boost day-to-day productivity and efficiency.

🔗 **Live Demo:** [Visit FocusFlow](https://suman-kumar-cse.github.io/focusflow/)

---

## ✨ Features

- **⏱️ Deep Focus Timer:** Built-in Pomodoro timer with 25-minute Focus and 5-minute Break modes.
- **✅ Smart Task Manager:** Add, complete, and delete daily tasks with color-coded priorities (**High**, **Medium**, **Low**).
- **📊 Live Efficiency Stats:** Real-time tracking for completed tasks, pending tasks, and finished focus sessions.
- **💾 Auto-Save:** Uses browser `localStorage` so your tasks and progress stay saved even after refreshing.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Responsive layout using Grid & Flexbox
- **JavaScript (Vanilla)** — Timer logic, DOM manipulation, and `localStorage` persistence
